# DealsHub - High-Performance Aceternity UI Deals-Blog

A production-ready, WordPress-compatible Deals-Blog built with Next.js, Tailwind CSS, and Aceternity UI components.

## Quick Start

```bash
cd deals-blog
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- 🎨 Aceternity UI Design - Modern, animated components
- 🌙 Dark Mode - Full light/dark mode support
- 📱 Responsive - Optimized for all screen sizes
- ⚡ Performance - Optimized images, code-splitting, SSR
- 🔍 SEO Ready - Meta tags, Open Graph, structured data
- 🇩🇪 German Content - Impressum, Datenschutz, German language
- 🔧 WordPress Ready - Prepared for Headless CMS integration
- 🤖 n8n Ready - Newsletter & automation prepared
